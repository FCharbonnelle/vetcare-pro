## 2025-05-22 - Focused Interaction for AI Diagnosis
**Learning:** Combining `autoFocus` on the primary symptom input with a reactive `disabled` state on the submission button (including visual opacity feedback) significantly reduces cognitive load in high-stakes contexts like AI-assisted pet health triage. It guides the user immediately to the task and prevents frustration from accidental premature submissions.
**Action:** Always implement `autoFocus` for single-purpose entry screens and ensure primary action buttons have clearly visible disabled states until required inputs are valid.
