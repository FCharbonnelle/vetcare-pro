## 2025-05-15 - Improving Accessibility and Keyboard Flow in Multi-Step Onboarding
**Learning:** For multi-step forms in React Native, using 'returnKeyType' and 'onSubmitEditing' on 'TextInput' components significantly improves the user flow by allowing users to progress through steps using the keyboard's "Next" or "Done" keys, rather than having to manually dismiss the keyboard and tap a button. Adding 'accessibilityRole="progressbar"' and 'accessibilityValue' to a custom progress indicator provides essential context to screen reader users about their position in a multi-step process.
**Action:** Always implement 'returnKeyType' and 'onSubmitEditing' in forms to provide a seamless keyboard experience. Ensure all custom interactive elements include 'accessibilityRole', 'accessibilityLabel', and 'accessibilityState' to maintain a high standard of accessibility.
