## 2025-05-14 - Accessibility and Keyboard UX in Onboarding
**Learning:** In a French-localized application, ensuring that accessibility labels (e.g., for progress bars) match the UI language is critical for a consistent screen reader experience. Additionally, providing standard keyboard-driven navigation (Return/Done keys) and using `KeyboardAvoidingView` are essential for high-quality mobile form UX.
**Action:** Always verify the primary language of the UI before adding accessibility labels, and implement standard keyboard interactions for all onboarding/form-based flows.
