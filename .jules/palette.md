## 2025-05-14 - Standardizing Accessibility Labels for Custom Components
**Learning:** In Expo Web / React Native Web, using `accessibilityRole="button"` and `accessibilityLabel` on `TouchableOpacity` ensures they are correctly identified as interactive elements by screen readers and testing tools like Playwright.
**Action:** Always add semantic roles and descriptive labels to icon-only buttons or card-like interactive components to improve the UX for assistive technology users.
